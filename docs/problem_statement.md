# Problem statement

The assignment provides paired scattering measurements `Y` and original grayscale images `X`. Given a 112×112 scattering image, recover the corresponding 28×28 image. The supplied test file contains four scattering measurements for final inference.

The original task description does not prescribe a particular reconstruction method. This repository therefore reports a calibrated physical inverse model together with two learning-based baselines and keeps the evaluation protocol explicit.
